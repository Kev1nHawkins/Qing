# 成员 5 社区与管理端设计基准

## 视觉概念

- 用户端：`member5-community-concept.png`
- 管理端：`member5-admin-concept.png`

## 设计系统

用户端沿用现有木棉红 `#9f2832`、暖纸色 `#f8f3ea`、深棕正文和克制金色强调。
页面采用“编辑型信息流 + 右侧发布栏”，避免重复卡片网格；大标题使用宋体气质，
控件与正文使用项目现有中文无衬线字体。

管理端沿用墨绿侧栏 `#19221f`、冷浅灰背景 `#f4f6f4`、白色表格面板和金色选中态。
审核页保持表格主导，不增加图表或复杂运营模块；详情抽屉只展示审核决策所需信息。

## 组件与交互

- 用户端：状态筛选、帖子卡片、文化标签、发布表单、评论抽屉、点赞/收藏选中态。
- 管理端：状态指标、状态标签页、搜索、分页表格、内容审核抽屉。
- 移动端：用户端改为单列，信息流优先，顶部发布入口滚动到后置发布栏；
  底部导航保持可见且无横向溢出。
- 动效仅用于加载反馈，并尊重 `prefers-reduced-motion`。

## 可见文案白名单

首屏固定文案：`共创社区`、`发布作品`、`全部`、`AI作品`、`校园打卡`、
`文化寻迹`、`为岭南文化写下新的注脚`、`点赞`、`评论`、`收藏`。

管理端固定文案：`社区审核`、`全部`、`待审核`、`已发布`、`已驳回`、
`已下架`、`搜索标题或作者`、`内容`、`作者`、`关联内容`、`数据`、
`状态`、`发布时间`、`操作`、`预览`、`通过`、`驳回`、`下架`、`内容审核`。
